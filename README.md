# 내가 하지 않은 말

중학생 대상 AI 윤리 체험(약 15분). 휴대폰 화면 안에서, AI가 만든 내 목소리 하나로 하룻밤 사이 학교폭력 가해자로 몰리는 일을 겪고, 되감기로 네 군데 원인을 막아 본다.

- 플레이: `index.html?run` (처음부터), `?run&phase1` (1단계부터), `?run&phase2` (되감기부터)
- 화면 시안 모음: `index.html`
- 데스크톱, 태블릿, 휴대폰 화면 크기에 맞춰 배치가 바뀐다.

## 로컬에서 실행

빌드 없이 정적 파일만 있다. 캐시를 끈 개발 서버:

```bash
python3 serve.py .
```

브라우저에서 `http://127.0.0.1:8765/?run`을 연다.

## 개인정보

- 입력한 이름은 기기 안에서만 쓰고 저장하거나 보내지 않는다.
- 마이크와 카메라는 열지 않는다. 녹음 장면은 연출이다.
- 인물 사진은 모두 AI로 생성한 가상 인물이다. 실제 학생의 얼굴이나 목소리는 쓰지 않는다.

## 그룹 통화 음성 (선택)

`tools/make-call-audio.mjs`가 ElevenLabs로 통화 대사를 `audio/`에 만든다. 키와 목소리 ID는 환경 변수로 넣는다. 파일이 없으면 통화는 소리 없이 진행된다.
